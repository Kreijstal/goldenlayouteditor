# Apple iWork documents

The lazy panel reads `.pages`, `.numbers`, and `.key` through a local module worker. It renders native static scenes with text, tables, charts, shapes, images, slide/sheet navigation and zoom. Saved formula values are shown without recalculation. Animation, transitions, videos, scripting and encrypted iwpv2 documents are not supported. This is a document preview, not an Apple application compatibility guarantee; unsupported object types and font differences can affect appearance.

Source: Apache-2.0 Flyfish renderer-iwork, e03662c883cdd089814d2d21e4c805b9d7320e0f. Parser/model/Snappy code and scene rendering are retained. The host replaces framework zoom registration, worker URLs and lifecycle. Pinned keynote-archives 2.0.1, styled-exceljs 0.21.6 and xmldom 0.9.12 dependencies supply Protobuf, Numbers saved-value decoding and XML support; their notices and embedded runtime notices are retained.

Adaptations deliberately reject generic string-scanned IWA fallback scenes and propagate decoder failures. Application-specific Protobuf IDs 2, 4, 5 and 15 are decoded as Keynote archives only, avoiding collisions with unrelated Numbers/Pages messages. Corrupt typed records and Snappy/archive boundaries fail rather than silently dropping frames. Unknown schema types are outside the supported static scene subset. The same strict behavior applies to chart decoding.

The parser enforces upstream bounds: 256 MiB expanded content, 200:1 ZIP ratio, 250000 objects, 80 million image pixels, and depth 128; host input is bounded to 128 MiB. Tab closure and new picker loads cancel their worker. Keynote routing requires ZIP contents so text private keys keep their existing route. No external runtime requests are required.

`npm run test:iwork` covers authored Keynote XML and typed Pages IWA contracts, legacy Pages/Numbers parser contracts, rejection of string-only IWA data, controls, picker, malformed input, signature collision, lazy requests, URL disposal and worker cancellation. Fixtures include their licenses/provenance; native binary payloads are external test inputs. `TEST_IWORK_FIXTURE_DIR` points to the pinned upstream fixture directory to additionally test nine real legacy/historical/current native documents; current files are checked for two scenes and their known content markers. These tests establish static rendering and data extraction, not pixel identity to Apple's fonts/layout.
