# WordPerfect viewer

`.wp`, `.wp5`, `.wp6` and `.wpd` route to a lazy viewer using the real libwpd 0.10.3 / librevenge 0.0.6 WebAssembly parser. It renders parsed paragraphs, inline styles, headings, list markers, tables and merged cells, headers, footers and notes. Page layout is approximate and graphics are not rendered. Encrypted, malformed and unrecognized documents report parser errors. There is no printable-byte fallback.

The runtime, worker and renderer load only when the viewer opens. The worker has a 128 MiB input limit and a 60-second deadline; picker replacement and tab close terminate it. DOM text nodes protect decoded text and table cells; only parser-approved HTTP(S)/mailto links are rendered. The wire reader caps events and strings, and libwpd allocations are freed in `finally`.

Source: flyfish-dev/file-viewer commit e03662c883cdd089814d2d21e4c805b9d7320e0f, packages/renderers/wordperfect. The parser bridge and renderer retain their Apache-2.0 source attribution. `scripts/build-wordperfect.js` fetches that pinned checkout and verifies SHA-256 values for both generated runtime assets. To use an existing checkout, set GOLDENLAYOUT_FLYFISH_SOURCE; its revision must match. Runtime dependencies and corresponding source are served locally under `wordperfect-viewer/`: the MPL-2.0 license arm is selected for libwpd/librevenge, the bridge shim is MIT and the Boost subset is BSL-1.0. Source archives, provenance, license files, shim and upstream reproducible build scripts are copied alongside the runtime. The upstream build scripts retain their original directory conventions; see the pinned repository for rebuilding.

`npm run test:wordperfect` creates a minimal native WP5 document from original text and checks all four routing aliases, text safety, picker changes, invalid input, lazy loading, cancellation, disposal and local asset loading. Aliases use the same native document and do not imply four different native versions. Set TEST_WORDPERFECT_FIXTURE_DIR to the pinned upstream package's test/fixtures directory to additionally test genuine public documents from WP 4.2/5.0/5.1/6.x and a Corel WP6 document with tables, bold/italic/superscript, footer and footnote. Their provenance and checksums are recorded upstream; no external native corpus binaries are committed here.
