# Local media decoder viewer

The lazy media viewer decodes `.aif`, `.aifc`, `.aiff`, `.amr`, `.au`, `.caf`, `.snd`, `.oga`, `.weba`, `.m4b`, `.wma`, `.asf`, `.divx`, `.f4v`, `.flv`, `.m2v`, `.mpe`, `.mpv`, `.rm`, `.rmvb`, `.vob` and `.3g2` through local FFmpeg WebAssembly. Native stream metadata comes from ffprobe. Audio previews use PCM WAV; video previews use H.264/AAC MP4 so ordinary browser players can display decoded results.

This is a bounded preview: first 30 seconds, video up to 960×540 at 15 frames/s, source and output each capped at 64 MiB, a 60-second wall deadline and a 50-second codec deadline. Output-size checking occurs after allocation, so it is not a hard browser-memory guarantee. Unsupported codecs/features and invalid input report errors. Tested examples include WMV2/WMA2 ASF, MPEG-4 AVI/3G2, H.264 F4V, FLV1, MPEG-1/2 elementary/program streams and RV20 RealMedia; this does not promise every codec profile within those containers. AMR-NB speech frames are tested; FFmpeg's native decoder rejects SID comfort-noise frames. Longer sources show only a preview and source metadata.

The single-thread runtime requires no SharedArrayBuffer or cross-origin-isolation headers. Its module worker and WASM are copied locally and load only on opening a media file. Source bytes are copied before worker transfer. A new input or tab close terminates the previous worker; completion/errors also terminate it. Player object URLs are revoked on disposal. Input probing and conversion allow only file/pipe protocols, preventing media playlists from opening network resources.

Dependencies are pinned to @ffmpeg/ffmpeg 0.12.15 (MIT wrapper) and @ffmpeg/core 0.12.10 (GPL-2.0-or-later native runtime). Their upstream release/build source is ffmpegwasm/ffmpeg.wasm commit 71aa99d37c02a7b4c435275ca9ef50e612f6efa1 (v12.15), which pins FFmpeg n5.1.4 and Emscripten 3.1.40. `build-media-sources.py` packages that build project, FFmpeg, each native dependency referenced by its Dockerfile, Emscripten and its SDL 2.24.2 port. Revisions are recorded in public/licenses/imported-viewers/media/sources.json. Source archives and licenses are available alongside the generated runtime under media-viewer/source and media-viewer/licenses; dependency source archives retain their individual notices. These generated assets stay out of source control.

The wrapper worker receives one documented integration fix: core 0.12.10's JavaScript ffprobe glue discards the native return value, leaving `ret` at -1 after success. The worker captures that exact native result before the stock wrapper reads it. It does not infer success from a file or suppress failed exit codes. The source transformation is retained in scripts/build-media.js.

`npm run test:media-codecs` generates original red-frame video and a sine-wave tone through a local FFmpeg CLI, plus an original AMR-NB frame sequence. It then tests all 22 inputs through the browser WASM decoder, checks actual red pixels or decoded audio duration/energy, native stream metadata, picker changes, readiness cancellation, invalid media, worker/URL disposal, zero startup runtime requests and no external requests. The generated fixtures are temporary and contain no user media. The test requires the native ffmpeg executable; TEST_MEDIA_FIXTURE_DIR can reuse a generated corpus.
